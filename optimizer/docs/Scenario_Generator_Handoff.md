# Scenario Generator - Handoff

## Назначение

`scenario_generator.py` генерирует набор сценариев для проверки качества различных режимов установки.

Генерация выполняется относительно **текущего состояния установки**, а не по всему диапазону параметров.

Для каждого управляемого параметра создаются значения:

```text
current - 2*step
current - step
current
current + step
current + 2*step
```

где:

```text
step = 10% от полного допустимого диапазона
```

Значения автоматически ограничиваются `lower_bound` и `upper_bound`.

## Входные данные

### 1. `base_state.csv`

Одна строка с текущим состоянием установки.

Названия параметров должны совпадать с названиями в `controllable_bounds.csv`.

Пример:

```text
hdt_T6 = 354
hdt_F9 = 155
hdt_P13 = 3.82
```

### 2. `controllable_bounds.csv`

Содержит список параметров, которые разрешено изменять оптимизатору.

Формат:

```csv
parameter,lower_bound,upper_bound
hdt_T6,352,356
hdt_F9,150,160
hdt_P13,3.70,3.95
```

`lower_bound` и `upper_bound` являются жёсткими границами сценариев.

## Генерация

Запуск:

```powershell
python scenario_generator.py
```

По умолчанию используются:

```text
examples/base_state.csv
controllable_bounds.csv
```

Результат:

```text
scenarios.csv
```

## Пример

Если:

```text
current = 354
lower = 350
upper = 360
```

то:

```text
step = (360 - 350) * 0.10 = 1
```

Сценарии:

```text
352
353
354
355
356
```

Для трёх параметров максимум:

```text
5 × 5 × 5 = 125 сценариев
```

## Результат

`scenarios.csv` содержит исходное состояние с изменёнными управляемыми параметрами и дополнительный:

```text
candidate_id
```

Пример:

```text
candidate_id,hdt_T6,hdt_F9,hdt_P13,...
0,352,153,3.72,...
1,352,153,3.82,...
2,352,153,3.92,...
...
```

`candidate_id` используется для последующего связывания сценария с результатом Quality Agent.

## Взаимодействие с Quality Agent

Сгенерированные сценарии передаются в `predict_frame()` Quality Agent.

Quality Agent сам пересчитывает зависимые расчётные признаки/ВАК через `prepare_features()`.

`scenario_generator.py` **не занимается**:

* прогнозированием качества;
* проверкой содержания серы;
* Pareto-оптимизацией;
* выбором лучшего сценария;
* оценкой технологической безопасности.

Его единственная задача - сформировать допустимые сценарии изменения управляемых параметров.

## Важное ограничение

Текущий размер шага установлен как:

```python
STEP_FRACTION = 0.10
```

Количество шагов:

```python
N_STEPS = 2
```

Это параметры MVP и могут быть изменены после проверки чувствительности Quality Agent.

Сценарные прогнозы Quality Agent имеют исследовательский статус и не должны автоматически интерпретироваться как доказанный физический эффект.
