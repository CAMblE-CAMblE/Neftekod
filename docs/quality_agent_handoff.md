# Quality Agent Handoff

Автономный комплект текущего агента качества находится в `quality_agent_package/`.

Точка входа для коллеги: `quality_agent_package/README.md`.

В комплекте уже есть текущая модель `first_quality_current`, готовый `data/base_state.csv`, CLI для прогноза и оценки кандидатов, а также команда сборки нового базового состояния из пользовательских путей. Коммит и push для передачи комплекта не требуются.
